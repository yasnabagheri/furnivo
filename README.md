# 🛋️ Furnivo - Modern Furniture Store

Welcome to Furnivo! This is a professional e-commerce showcase for a modern furniture store. 

## 🚀 Project Overview
The goal of this project is to create a clean, minimalist, and responsive landing page for selling high-quality furniture. It focuses on semantic HTML and modern CSS layouts.

## 🛠️ Tech Stack
- HTML5: For a semantic and accessible structure.
- CSS3: For custom styling and responsive design.
- Git & GitHub: For version control and collaboration.

## 📂 Folder Structure
- `assets/`: Contains all the images and icons used in the project.
- `index.html`: The main entry point of the website.
- `style.css`: All the custom styles for the project.
